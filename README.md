# emojiseq

A formatter that cleans up messy emoji sequences in text.

## The problem

An emoji you see as one glyph is often several Unicode code points glued
together: a base character, optional skin-tone modifiers, zero-width
joiners (ZWJ) chaining multiple emoji into one, and variation selectors
that pick text vs. emoji rendering. Text that's been copy-pasted between
apps, hand-typed, or generated by something that doesn't understand this
frequently ends up with joiners that don't join anything, or variation
selectors with no base character to attach to. Most fonts render those as
a stray blank glyph or a visible tofu box.

`emojiseq` walks through text and:

- normalises it to Unicode NFC, so equivalent sequences look identical
- collapses runs of repeated zero-width joiners into one
- drops a zero-width joiner that has nothing valid before or after it
- collapses runs of variation selectors into the last one in the run
- drops a variation selector that has nothing valid before it

It does this as a stream. Composing accented characters correctly only
requires looking at a base character plus the combining marks stuck to
it, and deciding whether a joiner or selector is attached to something
real only requires one character of lookback and lookahead. So the whole
pipeline holds at most a handful of characters in memory regardless of
input size -- a 4 KB message and a 4 GB log file full of reactions are
handled the same way.

## Usage

As a library:

```python
from emojiseq import format_text

format_text("thumbs up‍‍")  # dangling/doubled joiner -> cleaned up
```

On a stream, which is the case this project actually cares about:

```python
from emojiseq import format_stream

with open("huge_chat_export.txt", encoding="utf-8") as src, \
     open("cleaned.txt", "w", encoding="utf-8") as dst:
    format_stream(src, dst)
```

From the command line, once installed:

```sh
emojiseq messy.txt -o clean.txt
# or, reading stdin and writing stdout:
cat messy.txt | emojiseq > clean.txt
```

`-o` can point at the same path as the input, to clean a file in place;
the write goes to a temp file in the same directory first and is only
swapped in once formatting finishes, so a failure partway through leaves
the original untouched.

Add `--stats` to get a summary on stderr of what was changed and how often
(composed clusters, dropped/collapsed joiners, dropped/collapsed selectors),
without disturbing the normalised text on stdout:

```sh
emojiseq messy.txt -o clean.txt --stats
```

`format_stream` returns the same summary as a `Stats` object, for callers
using the library directly.

## Installing

Standard library only, nothing to install for the code itself. To get the
`emojiseq` command on your PATH:

```sh
pip install -e .
```

## Status

Early skeleton. The joiner/selector cleanup handles the common cases
(dangling and repeated joiners, orphan and repeated selectors) and
`--stats` reports what it changed, but it doesn't yet validate whole
sequences against the Unicode emoji data files (ZWJ sequences, valid
modifier-base + skin-tone pairs, regional-indicator flags) -- see the
roadmap in commit history for what's next.
